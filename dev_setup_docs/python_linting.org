*** Pre-commit Hooks to run locally before a commit

This is the most popular and efficient method. It automatically runs and fixes files on your machine /before/ you commit them. This prevents bad commits from ever reaching GitHub.

1.  *Install pre-commit:*
    #+begin_src bash
    pip install pre-commit
    pre-commit install
    #+end_src

2.  *Create =.pre-commit-config.yaml= in your project root:*
    #+begin_src yaml
    repos:
    -   repo: https://github.com/astral-sh/ruff-pre-commit
        # Find the latest tag on GitHub.
        rev: v0.4.3
        hooks:
            # Run the linter.
            -   id: ruff
                args: [--fix]
            # Run the formatter.
            -   id: ruff-format
    #+end_src

Now, every time you =git commit=, =ruff= will automatically fix and format your staged files.

https://pycodestyle.pycqa.org/en/latest/intro.html

#+begin_src sh :tangle ~/.config/pycodestyle :mkdirp yes
  [pycodestyle]
  count = False
  # ignore = E501,E226
  max-line-length = 100
  statistics = True
#+end_src

** autopep8
Can then use autopep8 to format the file.
- uses pycodestyle configuration from above
https://pypi.org/project/autopep8/

*** install
#+begin_src shell
sudo dnf install python3-autopep8
#+end_src

*** running
#+begin_src shell
 autopep8 --in-place --aggressive <filename>
#+end_src
